# 모임콕 (가칭) 기획서

## 한 줄 소개
링크 하나로 일정 투표하고, 결과가 나오면 공지문까지 자동으로 써주는 동아리·학생회용 일정 조율 서비스

## 문제 정의
동아리·학생회 운영진은 when2meet이나 카톡 투표로 가능한 시간을 모으고, 결과를 직접 확인한 뒤, 공지문을 다시 손으로 써서 단톡방에 올린다. 투표 → 집계 → 공지 작성이 각각 따로 놀아서 손이 많이 가고, 누가 응답 안 했는지도 파악하기 어렵다.

## 대상 사용자
- 운영진: 행사를 만들고 투표를 열고 일정을 확정하는 사람
- 참여자: 링크를 받고 가능한 시간만 체크하는 사람 (로그인 없음)

## MVP 기능
1. 행사 생성: 행사 이름, 설명, 후보 날짜, 시간대 범위 입력 → 투표 링크 생성
2. 투표: 참여자가 이름 입력 후 가능한 시간 칸을 드래그로 체크
3. 결과 보기: 시간대별 가능 인원을 색 농도로 표시, 가장 많이 겹치는 시간대 하이라이트, 응답자 명단
4. 마감 및 확정: 운영진이 최종 일정 선택
5. AI 공지문 생성: 확정 일정·행사 정보를 바탕으로 Claude API가 공지문 초안 작성 (톤 선택: 정기모임 / MT·행사 / 공식 공지), 복사 버튼

## 확장 아이디어 (MVP 이후)
- 불참 사유 수집
- 구글 캘린더 추가 링크
- 카톡·디스코드 공유
- 참석 인원 기반 회비·장소 규모 추천
- 여러 행사를 관리하는 운영진 대시보드

## 기술 스택 (초안)
- 프론트: React (Vite) + Tailwind
- 데이터: Supabase (행사, 응답 저장)
- AI: Claude API (공지문 생성, 서버리스 함수에서 호출해 API 키 보호)
- 배포: Vercel

## 화면 구성
1. 메인: 새 행사 만들기 버튼
2. 행사 생성 화면
3. 투표 화면 (참여자용 링크)
4. 결과·확정 화면 (운영진용 링크)
5. 공지문 생성 결과 화면

## 진행 계획 (8주)
- 1주차: 주제 선정, 기획
- 2주차: 행사 생성 + 투표 화면 프로토타입
- 3주차: Supabase 연동, 실제 링크 공유되게
- 4주차: 결과 집계 화면
- 5주차: Claude API 공지문 생성
- 6주차: Vercel 배포, 디자인 다듬기
- 7주차: 동아리·학생회에서 실사용 테스트
- 8주차: 피드백 반영, 발표 준비
